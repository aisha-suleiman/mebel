# Разбор референсов по кадрам

Источник: `references/1–14.png`. Каждый кадр разобран по шести полям, затем кадры
сгруппированы в семьи стилей со словарём и рецептом сборки.

Цвета указаны на глаз по скриншотам — это ориентир для подбора, а не пипетка.
Гарнитуры определены по классу рисунка (гротеск, антиква, конденсед и т.д.),
точные названия по скриншоту установить нельзя.

## Семьи стилей

### Семья I. Тёплый редакторский минимализм

**Кадры:** `1`, `4`, `5`, `7`

**Словарь:** warm minimal · editorial · cream · greige · taupe · quiet luxury · negative
space · oversized wordmark · letter-spaced caps · bento grid · matte texture · muted
palette · photography-led · flat cards · no accent colour · slow rhythm

**Рецепт сборки:**

1. Фон кремовый или песочный, **не белый**. Белый оставить только для карточек.
2. Акцентного цвета нет вовсе. Цвет приходит из фотографии дерева и тканей.
3. Одна гарнитура. Вордмарк или заголовок — в 6–10 раз крупнее интерфейсного текста.
4. Надзаголовки — капс 12 px с разрядкой 0.14em, цвет приглушённый.
5. Фото в край в герое, дальше плитки разного размера с крупными внутренними полями.
6. Карточки плоские: граница 1 px, радиус 12, тень только на ховере.
7. Между секциями 100–160 px пустоты. Линий-разделителей нет.
8. Текстуры только матовые: штукатурка, лён, букле, шпон. Никакого глянца.

### Семья II. Дисплейный контраст (швейцарский плакат)

**Кадры:** `2`, `12`

**Словарь:** swiss typography · display type · tight tracking · type as image ·
full-bleed · black on off-white · condensed caps · italic serif accent · overlap ·
grid tension · stat row · brutal scale jump

**Рецепт сборки:**

1. Одно слово или одна цифра занимает 60–90 % ширины экрана.
2. Трекинг отрицательный: −0.02…−0.04em. Интерлиньяж 0.9–1.0.
3. Всё остальное — 12–14 px. Промежуточных кеглей нет, в этом весь приём.
4. Дисплейный текст **перекрывает** изображение и обрезается краем кадра.
5. Курсивная антиква на 1–2 слова как единственное смягчение — приём кадра `2`.
6. Цвет: чёрный на светло-сером. Цветного акцента нет.
7. Внизу — полоса из трёх чисел с тонкими разделителями, она «заземляет» композицию.

### Семья III. Чистый ритейл-каталог

**Кадры:** `13`, `14`

**Словарь:** ecommerce grid · product card · price-first · filter row · pagination ·
consistent crop · studio seamless · wishlist icon · circular add button · trust bar ·
category bento · promo band

**Рецепт сборки:**

1. Сетка 3 в ряд на десктопе, 2 на планшете, 1–2 на телефоне. Карточки одной высоты.
2. Все фото сняты при одном свете и кадрированы одинаково — это держит сетку
   сильнее любой типографики (`13` это соблюдает, `9` нет).
3. Карточка: фото 4:3 → название → мелкая строка характеристик → цена → действие.
4. Цена видна всегда, крупнее подписи.
5. Круглая кнопка «+» на фото внизу справа, иконка избранного вверху справа.
6. Над сеткой — строка табов и фильтр, под сеткой — пагинация.
7. Декор минимальный. Стикеры «−40 %» и рукописные стрелки из `14` — то, что
   отличает шаблон от магазина, который выглядит дорого.

### Семья IV. Тёмный крафт

**Кадры:** `3`, `6`, `8`, `9`

**Словарь:** dark craft · workshop · moody lighting · amber glow · gold CTA · serif
headline · condensed caps · vignette · rough timber · tool wall · heavy shadow ·
centered stack · concept ad

**Рецепт сборки:**

1. Фон тёмный: коричневый `#3A2A1C` или зелёный `#0E3B32`.
2. Один тёплый источник света в кадре, виньетка по краям.
3. Заголовок антиквой, подзаголовок капсом в разрядку, иногда скрипт третьей строкой.
4. Акцент золотой или янтарный, только на кнопках.
5. Композиция центрированная, текст поверх фото.
6. Фактура обязательна: пиленый брус, стружка, инструмент, стёганая кожа.
7. Слабое место семьи: лента из четырёх одинаковых иконобоксов (`9`) и стоковый
   реквизит превращают её в шаблон за один шаг. Держится только на честной съёмке.
8. Кадр `8` показывает, чем семья спасается: **одна идея вместо оформления** —
   нога слона на диване вместо абзаца про прочность.

### Семья V. Технический чертёж

**Кадры:** `10`, `11`, `12` (у `12` типографика из семьи II)

**Словарь:** technical drawing · dimension lines · callouts · orthographic ·
blueprint · measured drawing · exploded view · cabinet plan · millimetre spec ·
paper texture · pencil render · annotation

**Рецепт сборки:**

1. Объект один, показан целиком, без среды и без стилизованного интерьера.
2. Поверх — выносные размеры: тонкая линия, простые стрелки, подпись в рамке.
3. Единицы подписаны явно и одинаково: «195 см», «60 см».
4. Цвет служебных линий контрастный к объекту — красный (`10`) или синий (`11`).
5. Заливки плоскостей — два тона дерева, больше цветов не нужно.
6. Подложка светлая, бумажная. Тени мягкие или отсутствуют.
7. Размеры образуют вторую сетку поверх рисунка — именно она держит композицию.

## Что из этого работает для сайта МДФ-мебели

Пересечение семей I, III и V — это и есть система, записанная в
[design-system.md](design-system.md): воздух и типографика из I, товарная сетка с
видимой ценой из III, чертежи с размерами из V. Семья II даёт приём для первого
экрана. Семья IV взята точечно — бирюза из `3` и идея прочности из `8`, без тёмного
фона и золотых кнопок.
