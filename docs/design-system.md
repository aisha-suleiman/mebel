# Дизайн-система

Собрана из разбора `references/1–14.png`.
Проект: статичный сайт производителя бюджетной мебели из МДФ — кухни, шкафы, полки, столы.

---

## 0. Что показали референсы

14 кадров распались на три кластера, а не на один стиль.

**A. Тёплый редакторский минимализм** — `1` Tilesuite, `2` Hotle, `4` AURA, `5` NORDIQ,
`7` form&wood, `13` lano.
Кремовый фон, огромная типографика против мелкого интерфейсного текста, много воздуха,
фото как главный герой, плоские карточки. Самый крупный и самый согласованный кластер.

**B. Тёмный «крафтовый» шаблон** — `3`, `6`, `8`, `9`.
Тёмно-коричневые мастерские, золотые CTA, четыре одинаковых иконочных бокса, тяжёлые
тени, центрирование.

**C. Технические чертежи** — `10`, `11`, `12`.
Кухни в разрезе с выносными размерами (195 см, 93 см, 58 см), карандашные виды,
«PLANOS MUEBLES DE MELAMINA» — россыпь ортогональных проекций корпусной мебели.
Это не веб-дизайн, это **контент**: что показывать, а не как верстать.

### Что взято

Основа — кластер **A**. Из остальных взяты точечные решения:

| Взято | Откуда | Как применяется |
|---|---|---|
| Бирюза как акцент | `3` | единственный цвет интерфейса, CTA и тёмные секции |
| Тон натурального дерева | `6`, `10` | заливки чертежей и схем, `--wood` |
| Идея прочности | `8` | отдельная секция: один концепт + проверяемая цифра |
| Тяжёлый геометрический гротеск | `7` | дисплейные заголовки и вордмарк |
| Оформление карточек | `13`, `14` | товарная карточка — гибрид двух |
| Чертежи с размерами | `10`, `11`, `12` | секция модулей, SVG-графика |

### Что отброшено и почему

Тёмно-коричневый фон на всю страницу, золотые CTA и блоки из четырёх одинаковых
иконок (`6`, `9`) — самый узнаваемый признак шаблона. В бюджетном сегменте он
удешевляет сильнее, чем в премиальном: покупатель и так сомневается в качестве.
Бирюза из `3` при этом остаётся — она сочетается с деревом по принципу дополнительных
цветов: холодный сине-зелёный против тёплого оранжево-коричневого тона древесины.

### Оговорка

Большинство референсов кластера A — бренды дорогой мебели из массива (AURA, form&wood,
NORDIQ). Копировать их один в один для бюджетного МДФ опасно: премиальная подача
поднимает ценовые ожидания и приводит нецелевые заявки. Поэтому в системе намеренно
сохранены **цены на виду** в каждой карточке (как в `13` и `7`) и добавлен чертёжный
слой — он честен для МДФ и закрывает главный страх покупателя «а влезет ли в нишу 2.6 м».

## 1. Общее в референсах

### Типографика

| Приём | Где видно |
|---|---|
| Экстремальный скачок кегля: гигантский дисплей против 12–14 px интерфейса | `1` (TILESUITE во всю ширину), `2` (Hotle), `7` (form&wood), `12` (PLANOS) |
| Одна гарнитура на весь интерфейс + засечный курсив на 1–2 слова | `2` («*architecture*», «*live, work, and chill*»), `4`, `8` |
| Надзаголовки капслоком с разрядкой 0.12–0.16em | `1`, `5` (растянутый выключенный абзац), `7` («01/ About us») |
| Нумерация секций | `7` («01/»), `13` («\\03 (Каталог)») |
| Числа как дисплейный элемент | `2` (120+ / 15+ / 5+), `3` (255+) |
| Текстовый абзац мелкий, приглушённый, короткой строкой | `2`, `4`, `7` |

### Сетка

- 12 колонок, но контент лежит **плитками разного размера** — `4`, `14`.
- Товарная сетка строго по 3 в ряд, карточки одной высоты — `13`, `7`, `14`.
- Герой — фото **в край экрана**, без полей — `1`, `2`, `6`, `9`.
- Асимметрия: текст слева, объект справа; заголовок заезжает на фото — `2`, `7`, `14`.
- Пары фото 50/50 внутри секции — `7`.

### Палитра

- Тёплые нейтралы во всех 14 кроме `3`: крем, песок, тауп, коричневый, тёплый чёрный.
- Акцент либо янтарный (`9`, `14`), либо его нет вовсе (`1`, `4`, `7`, `13`).
- Настоящий «цвет» приходит из фотографии дерева, а не из интерфейса.
- Тёмные секции работают как контрастные блоки внутри светлой страницы, а не как фон
  всего сайта — `7` показывает это буквально.

### Ритм блоков

- Чередование светлая → светлая-альт → тёмная → светлая (`7`).
- Внутри секции всегда один порядок: **мелкий лейбл → крупный заголовок → короткий
  абзац → сетка**.
- Секции разделяются воздухом, а не линиями и полосками-разделителями.
- Полоса с числами как сбивка ритма — `2`, `3`.

### Пространство

- Внешние поля щедрые на светлых секциях, нулевые на герое.
- Карточки плоские: граница или очень мягкая тень, без «объёма» — `4`, `13`.
- Текстовый блок никогда не на всю ширину — 45–65 знаков.
- Пустота и есть сигнал качества: в `1`, `4`, `7`, `13` её больше, чем контента.

## 2. Токены

```css
:root {
  /* Нейтралы */
  --bg:           #F7F4EF;  /* крем, основной фон */
  --bg-alt:       #EDE7DC;  /* песок, чередующаяся секция */
  --surface:      #FFFFFF;  /* карточка на светлом */
  --ink:          #1C1A16;  /* тёплый почти-чёрный, заголовки */
  --ink-2:        #4E4840;  /* основной текст */
  --ink-3:        #6F6960;  /* подписи, мета — проходит AA */
  --ink-4:        #8B847A;  /* только декор и disabled, НЕ для текста */
  --line:         #DCD5C9;  /* границы, разделители */

  /* Акцент — единственный цвет интерфейса */
  --teal-900:     #0E4A45;  /* фон тёмной секции */
  --teal-700:     #12655D;  /* CTA, ссылки, активные состояния */
  --teal-500:     #1E8F83;  /* ховер и графика, для мелкого текста не годится */
  --teal-100:     #DCEAE7;  /* фон чипа, бейджа, выделения */
  --dark-ink:     #EDF2F0;  /* текст на тёмном */
  --dark-ink-2:   #9FB5B1;  /* мета на тёмном */

  /* Дерево — только иллюстрации */
  --wood:         #B08356;  /* заливка чертежей и схем, НЕ элемент UI */
  --wood-light:   #D8BC98;

  --focus:        #2B6CB0;  /* видимый фокус, не трогать */

  /* Шрифты */
  --font-ui:      "Onest", "Manrope", system-ui, -apple-system, "Segoe UI", sans-serif;
  --font-accent:  "Lora", "PT Serif", Georgia, serif;   /* только курсив, 1–2 слова */

  /* Шкала кегля */
  --t-display: clamp(3rem, 9vw, 7.5rem);
  --t-h1:      clamp(2.25rem, 5vw, 4rem);
  --t-h2:      clamp(1.75rem, 3.2vw, 2.75rem);
  --t-h3:      clamp(1.25rem, 1.8vw, 1.5rem);
  --t-body:    1rem;
  --t-small:   0.875rem;
  --t-eyebrow: 0.75rem;

  /* Отступы, шаг 4 */
  --s-1: 4px;   --s-2: 8px;   --s-3: 12px;  --s-4: 16px;
  --s-5: 24px;  --s-6: 32px;  --s-7: 48px;  --s-8: 64px;
  --s-9: 96px;  --s-10: 128px; --s-11: 160px;
  --section-y: clamp(64px, 10vw, 160px);

  /* Геометрия */
  --r-sm: 4px;  --r-md: 12px;  --r-lg: 20px;  --r-pill: 999px;
  --shadow-hover: 0 8px 24px rgba(28, 26, 22, 0.08);

  /* Контейнер */
  --max-w:  1280px;
  --gutter: clamp(20px, 4vw, 48px);

  /* Движение */
  --ease: cubic-bezier(0.22, 0.61, 0.36, 1);
  --dur:  240ms;
}
```

### Правила цвета

- Бирюза — **единственный** цвет интерфейса. Всё остальное тепло приходит из
  фотографии и из `--wood` в иллюстрациях.
- Градиентов в системе нет.
- `--wood` никогда не красит кнопку, ссылку или фон блока — только линии и заливки
  внутри чертежей.
- Тёмная секция всегда `--teal-900`, не чёрный и не коричневый.

### Про шрифты

Гарнитуры из референсов латиница-онли. Для русского нужна кириллица.

- **Onest** — геометрический гротеск, полная кириллица, веса 100–900. Ближе всего к
  вордмарку из `7`. Вся страница набирается им.
- **Lora Italic** — засечный акцент, приём из `2`. **Не больше двух слов на экран**,
  иначе получится ровно тот лакшери-перебор, которого мы избегаем.

Больше двух семейств на сайте не используется.

Поддержка кириллицы проверена по Google Fonts: у `Onest`, `Lora`, `Manrope` и `PT Serif`
отдаются подмножества `cyrillic` и `cyrillic-ext`. Подключение:

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Onest:wght@400;600;700;800&family=Lora:ital@1&display=swap" rel="stylesheet">
```

## 3. Типографика в применении

```css
.display {                 /* герой и вордмарк: приём из 1, 2, 7, 12 */
  font: 800 var(--t-display)/0.95 var(--font-ui);
  letter-spacing: -0.03em;
}
.h1 { font: 700 var(--t-h1)/1.05 var(--font-ui); letter-spacing: -0.02em; }
.h2 { font: 700 var(--t-h2)/1.1  var(--font-ui); letter-spacing: -0.015em; }
.h3 { font: 600 var(--t-h3)/1.25 var(--font-ui); }

.accent-word {             /* приём из 2: «кухня, которая *влезает*» */
  font-family: var(--font-accent);
  font-style: italic;
  font-weight: 400;
}

.eyebrow {                 /* приём из 1, 5, 7 */
  font: 600 var(--t-eyebrow)/1 var(--font-ui);
  letter-spacing: 0.14em;
  text-transform: uppercase;
  color: var(--ink-3);
}

.lede  { font: 400 var(--t-body)/1.6 var(--font-ui); color: var(--ink-2); max-width: 58ch; }
.meta  { font: 500 var(--t-small)/1.4 var(--font-ui); color: var(--ink-3); }
.price { font: 600 1.125rem/1.2 var(--font-ui); color: var(--ink); font-variant-numeric: tabular-nums; }
```

Правила:

- На экране **один** элемент крупнее `--t-h1`. Два гиганта рядом — сразу шум.
- Абзац никогда шире `62ch`.
- Заголовок секции — одна мысль в одну-две строки, перенос ставится руками через `<br>`
  на десктопе.
- Все цены и размеры — `font-variant-numeric: tabular-nums`, иначе цифры в сетке
  «пляшут».

## 4. Сетка

```css
.container {
  max-width: var(--max-w);
  margin-inline: auto;
  padding-inline: var(--gutter);
}
.grid  { display: grid; grid-template-columns: repeat(12, 1fr); gap: var(--s-5); }
.bleed { width: 100%; margin-inline: 0; padding-inline: 0; }   /* герой в край */
```

Раскладки и когда их брать:

| Раскладка | Колонки | Откуда | Для чего |
|---|---|---|---|
| Герой в край | bleed | `1`, `2` | первый экран |
| Текст + объект | 5 + 7, асимметрично | `7`, `14` | оффер, «о производстве» |
| Пара фото | 6 + 6 | `7` | до/после, интерьер + деталь |
| Бенто-плитки | 4/8, 8/4, 6/3/3 | `4`, `14` | категории товаров |
| Товарная сетка | 4+4+4 | `13`, `7` | каталог |
| Полоса чисел | 4+4+4 с линиями | `2` | цифры производства |
| Чертёж + выноски | 7 + 5 | `10`, `11` | размеры модулей |

Брейкпоинты:

- `1280px` — максимум контейнера.
- `1024px` — 12 колонок → 8, товарная сетка 3 → 2.
- `640px` — всё в одну колонку, `--gutter` 20 px, `--section-y` по нижней границе.

## 5. Ритм страницы

Порядок секций главной. Чередование фонов — приём из `7`.

```
1   Герой              bleed, интерьерное фото объекта      --bg
2   Категории          бенто: кухни / шкафы / полки / столы  --bg
3   Почему дешевле     текст + фото цеха, 3 пункта           --bg-alt
4   Прочность          концепт + проверяемая цифра (из 8)    --bg
5   Размеры и модули   чертёж с выносками (из 10–12)         --bg-alt
6   Цифры              3 числа в строку (из 2)               --teal-900
7   Каталог и цены     товарная сетка, цена в карточке       --bg
8   Работы             пары фото реальных объектов           --bg-alt
9   Как заказать       4 шага, нумерация 01–04               --bg
10  CTA                бесплатный замер + телефон            --teal-900
11  Футер                                                    --bg-alt
```

Правила ритма:

- Тёмных секций на странице **максимум две**, и они не соседи.
- Вертикальный отступ секции — всегда `--section-y`, без исключений.
- Между лейблом и заголовком `--s-4`, между заголовком и абзацем `--s-5`,
  между абзацем и сеткой `--s-7`.
- Линии-разделители между секциями не используются: разделяет фон и воздух.

## 6. Компоненты

### Кнопка

```css
.btn {
  font: 600 var(--t-small)/1 var(--font-ui);
  padding: 14px 24px;
  border-radius: var(--r-pill);          /* пилюля — из 7 и 14 */
  transition: background var(--dur) var(--ease), transform var(--dur) var(--ease);
}
.btn--primary { background: var(--teal-700); color: #fff; }
.btn--primary:hover { background: var(--teal-500); }
.btn--ghost   { background: transparent; color: var(--ink); border: 1px solid var(--line); }
.btn--ghost:hover { border-color: var(--teal-700); color: var(--teal-700); }
.btn--on-dark { background: var(--dark-ink); color: var(--teal-900); }
.btn:focus-visible { outline: 2px solid var(--focus); outline-offset: 3px; }
```

Один `--teal-700`-CTA на секцию. Если кнопок две — вторая становится `.btn--ghost`.

### Товарная карточка — гибрид `13` и `14`

```
┌──────────────────────────────┐
│  фото 4:3 на --bg-alt        │  ♡  иконка избранного вверху справа (13, 14)
│                          (+) │  круглая кнопка внизу справа (13)
├──────────────────────────────┤
│  Шкаф «Компакт»          h3  │
│  2000×600×16 мм, МДФ    meta │
│  от 12 400 ₽           price │
│  [ Рассчитать → ]    ghost   │  во всю ширину
└──────────────────────────────┘
```

```css
.card {
  background: var(--surface);
  border: 1px solid var(--line);
  border-radius: var(--r-md);
  padding: var(--s-4);
  transition: box-shadow var(--dur) var(--ease), transform var(--dur) var(--ease);
}
.card:hover { box-shadow: var(--shadow-hover); transform: translateY(-2px); }
.card__media { aspect-ratio: 4/3; background: var(--bg-alt); border-radius: var(--r-sm); }
.card__add {                          /* круглая «+» из 13 */
  width: 40px; height: 40px; border-radius: var(--r-pill);
  background: var(--ink); color: #fff;
}
```

- Цена видна **всегда**. Бюджетный сегмент выбирает сравнением; скрытая цена — главная
  точка отвала. Так же сделано в `13` и `7`.
- Карточка **не вкладывается** в другую карточку — ошибка `14`, не повторяем.
- Высота карточек в ряду одинаковая, изображения кадрированы одинаково.

### Блок чертежа — главный отличительный элемент

Прямо из `10`, `11`, `12`. Того, что есть у производителя и нет у перекупов.

- Фон секции `--bg-alt`, графика — SVG, не растр: масштабируется и весит килобайты.
- Линии контура `--ink` 1.5 px, заливка плоскостей `--wood` и `--wood-light`.
- Выносные размеры: линия `1px var(--ink-3)`, простые стрелки, подпись `.meta`
  с `tabular-nums`, единицы в сантиметрах — как в `10` и `11`: «195 см», «60 см».
- Справа столбец спецификации: плита, кромка, фурнитура, срок изготовления.

### Блок прочности

Идея из `8` (слон на диване), но без коричневого градиента и стокового пафоса:
один концептуальный визуал на страницу плюс **проверяемая цифра** — нагрузка на полку
в кг, число циклов петли, толщина кромки в мм. Цифра набирается как `.h1`,
пояснение — `.meta`.

### Полоса чисел

Приём из `2`: три числа, тонкие вертикальные линии между ними, фон `--teal-900`.

```
340+            12 лет            10 дней
кухонь          на рынке          средний срок
```

Число — `--t-h1` цветом `--dark-ink`, подпись — `.meta` цветом `--dark-ink-2`,
разделитель `1px solid rgba(237, 242, 240, 0.18)`.

### Шапка

По `1` и `7`: прозрачная поверх героя, текст `--dark-ink`. При скролле — фон `--bg`,
текст `--ink`, `border-bottom: 1px solid var(--line)`. Логотип слева, 4–5 пунктов
меню, справа телефон и `.btn--primary` «Замер».

## 7. Изображения

Съёмка готовых объектов есть, поэтому фото несёт страницу, а чертежи её дополняют.

- Пропорции: герой `21:9` или в край; карточка товара `4:3`; интерьерный кейс `3:2`.
- **Один свет и один баланс белого во всём каталоге** — иначе товарная сетка
  развалится. В `13` это соблюдено идеально, в `9` — нет.
- Предметка снимается на `--bg-alt`, а не на белом: белый фон на кремовой странице
  читается как дырка.
- Фото цеха — репортажные. Никаких стоковых «рук с рубанком».
- Интерьерные кейсы — реальные квартиры, а не рендеры: в этом весь смысл секции 8.
- `loading="lazy"` на всём ниже первого экрана, явные `width` и `height` против
  сдвигов вёрстки.

## 8. Движение

Референсы статичные, поэтому движения минимум.

- Появление секции: `opacity 0→1` + `translateY(8px→0)`, `--dur`, срабатывает один раз.
- Ховер карточки: подъём 2 px и мягкая тень.
- Ховер фото: `scale(1.02)` внутри `overflow: hidden`.
- Никакого параллакса, пиннинга, скролл-джекинга и счётчиков-«тикеров».

```css
@media (prefers-reduced-motion: reduce) {
```

## 9. Доступность

Посчитанные контрасты палитры:

| Пара | Контраст | Где можно |
|---|---|---|
| `--ink` на `--bg` | 15.8 : 1 | любой текст |
| `--ink-2` на `--bg` | 8.2 : 1 | любой текст |
| `--ink-3` на `--bg` | 5.0 : 1 | подписи и мета от 14 px |
| `--ink-4` на `--bg` | 3.4 : 1 | **только декор**, не текст |
| `--teal-700` на `--bg` | 6.3 : 1 | ссылки и текст |
| белый на `--teal-700` | 6.9 : 1 | текст кнопки |
| `--teal-500` на `--bg` | 3.6 : 1 | крупный текст от 24 px и графика |
| `--dark-ink` на `--teal-900` | 8.9 : 1 | любой текст |
| `--teal-500` на `--teal-900` | 2.5 : 1 | **только графика**, не текст |

Остальное:

- Фокус `--focus` виден всегда, `outline` не удаляется ни на одном элементе.
- Кликабельная зона от 44×44 px, включая круглую «+» на карточке.
- Заголовки идут по порядку, один `h1` на страницу.
- Иконка избранного — кнопка с `aria-label`, не `<div>`.

## 10. Чего не делаем

Взято из слабых мест самих референсов:

- ❌ Тёмно-коричневый фон на всю страницу (`6`, `9`) — душно и выглядит стоково.
- ❌ Четыре одинаковых иконочных бокса в ряд (`9`) — блок ничего не сообщает.
- ❌ Золотые и янтарные CTA (`9`, `14`) — акцент в системе только бирюзовый.
- ❌ Стикеры «Up to 40% OFF» и рукописные стрелочки (`14`) — удешевляют.
- ❌ Тяжёлые тени и карточка внутри карточки (`14`).
- ❌ Центрирование всего подряд (`6`, `8`).
- ❌ Градиенты. В палитре их нет вообще.
- ❌ Скрытые цены и «уточняйте по телефону».
- ❌ Больше двух шрифтовых семейств.
- ❌ `--wood` в интерфейсе: кнопках, ссылках, фонах секций.
